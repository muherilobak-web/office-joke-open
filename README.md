A single-line joke about office life for the Make the AI Judge Laugh bounty. It takes the most familiar office ritual — the meeting that could have been an email — and turns it somewhere unexpected: the meeting doesn't just waste time, it reproduces, spawning a follow-up to investigate its own early finish.

## Run

```sh
node main.ts
```

Writes the joke to `/output/entry.txt` with no trailing newline. Deterministic, no network, no dependencies.
